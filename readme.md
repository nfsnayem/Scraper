# Mobile Specification Scraper

## How to Use?

1. Clone the repository:
   ```bash
   npm install
   ```
2. After installing dependencies, start the application:

   ```bash
   npm start
   ```

3. To use the application you have to use the Mobilo extension
4. You can only use it in Mobiledokan.biz

to check API run

```bash
localhost:3030?url=<mobiledokandeviceUrl>
```
